# امپراتوری چوسان — بازی شبیه‌سازی مدیریت کشور

بازسازی وب‌محور بازی چت‌محور «امپراتوری چوسان» (که قبلاً با ChatGPT اجرا می‌شد). یک هوش
مصنوعی گیم‌مستر (از طریق OpenAI API) نقش راوی/کارگردان بازی را بازی می‌کند و بازیکن در
نقش «روهی کبیر»، پادشاه چوسان، تصمیم می‌گیرد.

سند کامل جهان، شخصیت‌ها، نهادها و قوانین بازی (که سیستم‌پرامپت گیم‌مستر از آن ساخته
می‌شود) اینجاست: [`../docs/joseon-game-bible.md`](../docs/joseon-game-bible.md).

---

## 🧭 راهنمای اجرا برای کسی که برنامه‌نویس نیست

اگه اولین بارته با یه پروژه‌ی کد کار می‌کنی، این بخش رو دنبال کن — قدم‌به‌قدم و بدون فرض دانش قبلی.

### قدم ۱ — نصب Node.js (یک‌بار، روی کل کامپیوتر)

این پروژه با زبان جاوااسکریپت نوشته شده و برای اجراش به برنامه‌ی رایگان **Node.js** نیاز داری.

1. برو به [nodejs.org](https://nodejs.org)
2. دکمه‌ی سبزرنگی که نوشته **LTS** رو دانلود و نصب کن (Next → Next → Install، مثل هر نرم‌افزار دیگه).
3. بعد از نصب، سیستم رو یک بار ری‌استارت کن (اختیاری ولی مطمئن‌تره).

### قدم ۲ — باز کردن ترمینال (خط فرمان) توی پوشه‌ی پروژه

- **ویندوز:** پوشه‌ی `roxavito` که این پروژه توشه رو باز کن، توی فضای خالی پوشه (نه روی یه فایل) کلیک راست کن و **«Open in Terminal»** یا **«Open PowerShell window here»** رو بزن.
- **مک:** توی Finder پوشه‌ی `roxavito` رو باز کن، راست‌کلیک روی پوشه → **Services → New Terminal at Folder** (یا برنامه‌ی Terminal رو باز کن و بنویس `cd ` و پوشه رو بکشی و رها کنی توش، بعد Enter بزن).

یک پنجره‌ی سیاه/تیره با متن باز می‌شه — همون ترمیناله. از این به بعد فقط باید دستورهای زیر رو دقیقاً همون‌طور که نوشته شده کپی/پیست کنی و Enter بزنی.

### قدم ۳ — نصب و راه‌اندازی سرور (بک‌اند)

توی همون ترمینال:

```bash
cd game/server
npm install
```

صبر کن تا تموم بشه (چند ثانیه تا چند دقیقه، بسته به اینترنت).

حالا باید یه فایل تنظیمات بسازی که کلید API توش باشه:

1. توی پوشه‌ی `game/server` یه فایل به اسم دقیقاً `.env` بساز (با یک ادیتور متن مثل Notepad یا VS Code — دقت کن اسمش با نقطه شروع می‌شه و پسوند نداره).
2. این متن رو توش بنویس (به‌جای `your-openai-api-key-here` کلید واقعی OpenAI خودت رو بذار):

   ```
   OPENAI_API_KEY=your-openai-api-key-here
   OPENAI_MODEL=gpt-4o
   ```

   > ⚠️ **مهم درباره‌ی کلید API:** کلید API مثل رمز عبوره — هرگز توی چت با هوش مصنوعی، ایمیل، یا جای عمومی پیستش نکن، فقط داخل همین فایل `.env` روی کامپیوتر خودت. اگه یه کلید رو جایی (مثلاً توی یه چت) به اشتراک گذاشتی، برو به پنل OpenAI (platform.openai.com → API keys) و همون کلید رو **Revoke/Delete** کن و یه کلید جدید بساز — چون کلید افشا‌شده ممکنه توسط دیگران هم قابل استفاده باشه.

3. فایل رو ذخیره کن.

حالا سرور رو روشن کن:

```bash
npm run dev
```

اگه خط `👑 سرور امپراتوری چوسان روی پورت 8787 در حال اجراست.` رو دیدی، یعنی سرور روشنه. **این پنجره‌ی ترمینال رو باز نگه‌دار و نبندش.**

### قدم ۴ — نصب و راه‌اندازی رابط بازی (فرانت‌اند)

یک پنجره‌ی ترمینال **جدید** باز کن (طبق قدم ۲) و این‌بار:

```bash
cd game/client
npm install
npm run dev
```

بعد از چند ثانیه یه آدرس مثل `http://localhost:5175/` نشون داده می‌شه.

### قدم ۵ — بازی کردن

مرورگر (کروم/فایرفاکس/سافاری) رو باز کن و برو به:

```
http://localhost:5175
```

بازی از همون‌جایی که تاریخچه‌ی اصلی متوقف شده بود شروع می‌شه (سه‌شنبه عصر، سال نهم سلطنت
روهی کبیر). توی کادر پایین صفحه بنویس پادشاه چی‌کار می‌خواد بکنه و Enter بزن.

هر بار که خواستی بازی کنی، فقط قدم‌های ۳ و ۴ (بدون `npm install`، فقط `npm run dev` توی هر دو
پوشه) رو تکرار کن و دوباره برو `http://localhost:5175`.

### اگه مشکلی پیش اومد

- **پیام «command not found» یا «npm شناخته نشد»:** یعنی Node.js درست نصب نشده یا ترمینال رو بعد از نصب نبستی/نبازکردی. ترمینال رو ببند، دوباره باز کن و امتحان کن.
- **صفحه‌ی بازی باز نمی‌شه:** مطمئن شو هر دو ترمینال (سرور و کلاینت) هنوز باز و روشن‌اند.
- **پیام خطای قرمز توی خود بازی وقتی پیام می‌فرستی:** معمولاً یعنی کلید API اشتباهه، اعتبارش تموم شده، یا حسابت شارژ/بیلینگ نداره — پنل OpenAI رو چک کن.

## معماری

```
game/
├── server/   بک‌اند Node.js + Express — تماس با OpenAI API، مدیریت وضعیت بازی (save)
└── client/   فرانت‌اند React + Vite — چت با گیم‌مستر + پنل‌های وضعیت زنده (خزانه/ارتش/جناح‌ها/...)
```

- **چرا بک‌اند لازم است:** کلید API هرگز نباید در مرورگر قرار بگیرد. سرور تنها واسط امن
  بین کلاینت و OpenAI API است و همچنین وضعیت بازی (save) را روی دیسک نگه می‌دارد.
- **ذخیره‌سازی:** ساده و فایل‌محور (`server/data/state.json` و `history.json`) — برای یک
  بازیکن روی یک ماشین کافی است. برای چندکاربره/دیتابیس واقعی نیاز به توسعه دارد.
- **مکانیزم وضعیت زنده:** گیم‌مستر در انتهای هر پاسخ یک بلوک JSON مخفی (`<STATE>...</STATE>`)
  برمی‌گرداند که سرور آن را استخراج، با وضعیت قبلی ادغام (merge) و ذخیره می‌کند. این بخش هرگز
  به کاربر نمایش داده نمی‌شود — فقط پنل‌های وضعیت را در فرانت‌اند به‌روزرسانی می‌کند.
- **ساختار حکومت (شخصیت‌ها/نهادها) در کد قفل شده**، نه در خروجی مدل — دقیقاً طبق یکی از
  مهم‌ترین قوانین طراحی استخراج‌شده از بازی اصلی: «تغییر پرسنل فقط با رویداد درون‌داستانی
  مجاز است، نه فراموشی یا خطای مدل».

## تنظیمات

در `server/.env`:

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `OPENAI_API_KEY` | کلید API اوپن‌ای‌آی (الزامی) | — |
| `OPENAI_MODEL` | مدل مورد استفاده برای گیم‌مستر | `gpt-4o` |
| `OPENAI_MAX_TOKENS` | سقف توکن خروجی هر پاسخ | `4096` |
| `PORT` | پورت سرور | `8787` |

## شروع دوباره‌ی بازی

دکمه‌ی «شروع دوباره» در بالای صفحه، تاریخچه و وضعیت را پاک کرده و بازی را از نقطه‌ی
شروع (`server/data/initial-state.json`) دوباره آغاز می‌کند.

## محدودیت‌های نسخه‌ی فعلی (MVP) و ایده برای توسعه‌ی بعدی

- بدون streaming — پاسخ گیم‌مستر یک‌جا نمایش داده می‌شود (نه تایپ تدریجی).
- بدون احراز هویت/چندکاربره — برای بازی شخصی روی یک ماشین طراحی شده.
- تاریخچه‌ی کامل مکالمه هر بار به مدل ارسال می‌شود؛ در صورت طولانی‌شدن خیلی زیاد بازی،
  ممکنه لازم بشه تاریخچه خلاصه‌سازی (summarize) بشه تا از سقف کانتکست مدل رد نشه.
- کدکس/دانشنامه‌ی درون‌بازی (طومارهای یانگ چئول) هنوز به UI اضافه نشده؛ در سند
  `joseon-game-bible.md` بخش ۷ مستند شده و می‌تواند بعداً به یک پنل تبدیل شود.
